# 单题分析使用说明

同一套规则既能分析一个小问，也能分析一道含多个小问的题。程序负责复算；完整解题、核验、评分证据与教学批注仍由教师或AI完成并审校。

## 给AI的任务写法

将通用提示词与材料一起提供，再写：

> 使用单题模式分析这道题。保留原题、答案与解析，在关键步骤旁加入批注；逐小问给出H/C/T/D/B及完整依据。说明入口、关键步骤、易错边界、讲评重点与前问引用关系。配分未知不均分，冲突单列。省略整卷统计，交付教师阅读版及评分明细。

## 程序复算

```bash
# 一个小问：直接传入单小问对象，自动识别
python -m question_difficulty examples/single-question.json --output single-result.json
# 一道三小问题：文件中已声明scope为question
python -m question_difficulty examples/single-multipart.json --output multipart-result.json
# 旧questions数组也可显式指定单题范围
python -m question_difficulty examples/minimal.json --scope question --output result.json
```

单小问对象输出question结果，不生成分布统计；多小问题仍用questions数组，每项是一个独立小问。数组默认保留旧整卷行为；不能仅凭数组长度推断是一道题还是一张卷。文件里的scope或命令中的--scope用于明确范围，命令参数优先。

多小问题结果将whole_paper_weighted_mean改为whole_question_weighted_mean，中文口径改称整题。未知配分时该项为空，不能均分。其他统计用于检查数据，教师正文无需照搬所有小样本统计。

已有score_question函数可复算一个小问；score_paper保留原整卷接口。此次只增加范围选择，未改变任何评分公式。

## 完整示范

[2024年第21题公开分析示范](单题示范-2024第21题.md)包含原创审校解、就地批注、全部评分依据与讲评建议。[输入明细](../examples/single-multipart.json)可复算三个小问。

本地完整教师版另保留原题和来源解析；公开仓库延续既定材料范围，使用来源定位和原创分析，不新增第三方原文分发。

## 使用边界

删去可引用的前问结论，可能增加必需推理；保留完整条件和同一主解法时才应复用原评分。待复核问仍输出空分数，不能因进入单题模式自动解除冲突。D不是实际失分率，整题平均数不代表正式等级。
