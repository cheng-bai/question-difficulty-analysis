# 算法说明与输入约定

## 六维与步骤负荷

步骤是“产生一个有意义中间结论”的单位；阶段只组织方向，不重复计分。每步只取一个主要类型，依赖关系只包含当前小问中的步骤；已经允许引用的前问结论作为输入，不再重新计入工作量。

| 维度 | 0 | 1 | 2 |
|---|---|---|---|
| K 知识识别 | 直接公式或定义 | 标准变式 | 未显露关系或非常规组合 |
| R 条件推理 | 单步直接推出 | 两三次常见转换 | 隐含条件、逆向构造或长依赖 |
| A 运算 | 短常规运算 | 中等化简或联立 | 长含参链、高错误敏感计算 |
| V 表征转换 | 无 | 一次 | 多次或双向 |
| P 参数边界 | 无额外负担 | 单一参数或边界 | 多分支、复杂量词或制约边界 |
| I 知识交汇 | 单模块 | 两模块浅配合 | 同一关键推理深度耦合 |

$$s_i=0.20K_i/2+0.25R_i/2+0.15A_i/2+0.15V_i/2+0.15P_i/2+0.10I_i/2.$$

每维必须附该步实际数学动作的证据。验证器只检查非空与格式，不能理解证据是否真实充分；这一点必须由审校者负责。

## H、C、T、D与B

$$H=\operatorname{round}(100\max_i s_i).$$

对每条根到终点的依赖路径，令：

$$d_j=\min(1+0.1(j-1),1.3),\qquad e_j=s_jr_jd_j.$$

确认机械重复时，同一重复组在该路径的首次、第二次、以后分别取$r=1,0.7,0.4$；其他步骤$r=1$。重复组需要`repeat_group`及`repeat_evidence`，同类型ID本身不会触发折扣。

$$E=\max_{\text{依赖路径}}\sum_j e_j,\qquad C=\operatorname{round}(100[1-\exp(-E/3)]).$$

多前置步骤表示全部是必要前置，但C只取通往该步的最重单条链。程序不会把并列分支负荷相加，分支工作量由独立标记提醒。并列备用解法不应同时放入主解输入。

T依次评估入口隐蔽、竞争入口、错误发现延迟、回退范围、边界遗漏，各取0/1/2；未知不能填0。

$$T=10\sum_{i=1}^5t_i,\qquad D=\operatorname{round}(0.45H+0.35C+0.20T).$$

D档位为0—34基础、35—64中档、65—100难题。B独立取0—3，描述直接识别、常见组合、非显然转化、缺乏提示的明显发现门槛，不参与D。

全部公式使用非负四舍五入，只在标明round的位置取整。程序内部使用十进制权重与40位计算精度，序列化展示s/e为普通数值；不会先把s/e截断再计算。

## 输入格式

文件最外层是`{"questions": [...]}`；最小可运行例见[示例](../examples/minimal.json)。

| 字段 | 含义 |
|---|---|
| id | 小问ID，字符串；同一year内唯一 |
| year | 可选年份，用于案例归属；程序不会自动分年统计 |
| score | 小问分值，正数或null；不是难度分 |
| pending、issue | 是否因题意/证据冲突暂停确定评分及原因 |
| steps | 主解法全部有意义步骤 |
| steps[].id/type_id | 实例ID与主要类型ID，不混用 |
| input/action/output | 该步的条件、数学动作和所得结论 |
| dependencies | 当前小问中的前置步骤ID；无前置用空数组 |
| dimensions | 恰好K/R/A/V/P/I六个0/1/2整数 |
| dimension_evidence | 对应六维依据；0分也需说明为何直接或无额外负担 |
| t | 按既定次序给五个0/1/2值 |
| T_evidence | 五个对象，包含evidence，可附item与value核对 |
| B、B_evidence | 突破等级与具体转化依据 |
| branches | 必做终端分类数；无分类填0 |
| repeat_group/repeat_evidence | 可选，仅用于有依据的机械重复 |

已存在的H/C/T/D/s/path等历史字段会被忽略，始终从步骤与T重新计算。代码不覆盖输入文件，以免丢掉证据。

`pending=true`至少需id和issue；确定分数全部输出null，不将条件性步骤包装成确定分值。已知小问分值仍可保留，用于覆盖率分母。

## 统计边界

有效均值、中位数、最高值与总体标准差只使用非pending的小问，同时报告有效/全部数量。六维画像是先取每问每维步骤峰值，再对有效问平均。

程序仅在全部小问配分已知且全部可评分时给`whole_paper_weighted_mean`。否则只给分值明确且可评分子集的`known_points_weighted_mean`，并报告已知分值范围的覆盖率。这个子集指标不能改名为整卷难度。

图有循环、重复ID、缺失前置节点或路径数量超过上限时明确失败。默认最多100000条路径；超大图应先检查划步粒度，也可通过函数参数明确提高上限。等负荷路径按ID字典序选择，保证复算稳定。

## 已知方法限制

规则未校准；证据好坏不能只靠程序检查。C随划步粒度变化，不能描述所有必做分支总量。B及低估提醒只是复核信号，不是实测纠偏模型。不同年份、课程范围、主解选择改变时，应记录版本并重新评估。
