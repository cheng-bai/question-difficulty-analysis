# 发展规划

本规划按完成条件推进，不承诺未经评估的日历日期。先把材料与评分依据做可靠，再扩大自动化范围。各阶段不是已实现功能列表。

## v0.1.0：可运行、可复算的开源基线

当前发布包含规则核心、命令行入口、案例数据、分析提示词、项目文档和测试。目标是让另一台电脑无需私人路径和密钥，就能复算既有106问并识别9问未定分。

验收：最小示例可运行；115问数量保持28/29/29/29；106问H/C/T/D/B与快照一致；循环依赖和缺证据被拒绝；缺配分不生成整卷加权值；公开文件不含私人绝对路径。

## v0.1.1：单题模式已补齐

已增加提示词范围识别、单题输出结构、程序单小问入口及多小问整题范围，提供2024年第21题示范。教师版仍需人工/AI审校，尚未实现自动读取任意Markdown并生成完整报告。后续材料规范应同时覆盖单题与整卷，验证前问条件是否完整。

## 第一优先级：v0.2 材料与数据规范

| 任务 | 完成标准 | 依赖 |
|---|---|---|
| 复核2025第14题完整问法 | 找到可定位原卷证据，确认指数与充分/必要方向 | 原卷或可靠原始图 |
| 复核2025第17(2)阈值 | 确认210还是211，重解并记录版本变更 | 原卷 |
| 复核2025第21(3)偶性 | 确认条件；保留旧版本及影响说明 | 原卷 |
| 核2023第20(3)与2024第20(3) | 解决交点存在与延长方向，不用猜测修题 | 原卷与图 |
| 核其余2025版本差异 | 第7、10、11、12题各有证据和处置结论 | 原始图文 |
| 补小问分值 | 仅接受明确配分，记录出处；找不到保持未知 | 官方或可靠评分细则 |
| 定版数据格式 | 发布格式版本、迁移规则与校验样例 | 多份真实输入 |

验收：每个冲突要么有证据解除，要么明确保留待复核；不能为了提高覆盖率把疑点改成“已解决”。旧快照可追溯，新增评分由程序重新计算。

## 第二优先级：v0.3 独立复评与粒度检验

邀请至少两名能独立解题的评阅者，先对选定子集盲于既有分数地评分；子集应包含基础题、短题突破、长依赖链、分支题和旧公式可能低估题。人数与样本规模由实际招募确定，不把计划写成已完成。

记录每步六维分歧、划步差异、T证据是否充分、主路径选择和B判断。先解释分歧，再讨论合并规则；不要只求平均掩盖方法冲突。

对同一主解法制作合理的粗细两种划步，检查C、D和档位是否改变。由此明确哪些结论稳定、哪些对粒度敏感。

验收：有独立评分原记录、分歧表、裁决依据与修订日志；统计指标只描述真实样本，不编造评阅一致率。权重仍保持v1.1，除非另开实验规则版本。

## 第三优先级：v0.4 教师工作流

计划增加受控Markdown输入、图形清单、教师阅读版生成和复核清单导出。支持“题干—答案—解析—就地批注—评分附录”的标准结构，并保留原版本。

AI可用于建议入口、补写候选解、划步和初评；每条建议必须有题目位置和解法依据，默认不是已核验事实。Jev若接入，只负责前期难点与疑点筛查，不能替代完整解题和证据审校。

验收：至少两种不同来源版式可导入；不漏选项、图形、小问和分值；错误和缺图被显式报告；教师可以修改某步后重新计算；生成稿与来源逐项对应。PDF导出需独立检查公式、分页和图片，不能只看文件生成成功。

## 后续实验：真实数据校准

在取得合法使用、去身份化的真实答卷数据后，研究结构分与小问作答结果之间的关系。须预先说明目标：解释结构、排序难度还是预测得分；不同目标不共用未经检验的结论。

设计独立验证集，按题目或试卷划分，避免同题变式泄漏；同时考虑课程范围、题型、配分和样本来源。公开样本覆盖与误差，不把单地单年的结果泛化为所有学生。

权重或阈值变化使用新算法版本，与现行规则结果并存。只有真实数据支持时，才使用“校准难度”“预测”之类说法。

## 暂不优先做的事情

- 无证据的一键难度星级、面向个人的自动成绩预测。
- 为了图表好看而补齐不存在的小问或猜配分。
- 先做复杂网页界面，再回头补材料与数学审校。
- 把大量未核验自动评分作为训练标签扩充“标准题库”。

## 维护方式

数学纠错、材料冲突、评分分歧、代码缺陷分别记录。每次发布说明算法版本、数据版本和程序版本；变更影响题目范围与统计分母要明确。

新案例需说明来源和可公开范围；不收集学生姓名、联系方式、学号等身份信息。公开案例不等于自动获得原试卷再分发权。
