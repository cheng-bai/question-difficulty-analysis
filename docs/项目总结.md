# 项目总结：题目难度分析算法

## 1. 原始任务与成功标准

本项目的直接任务，是按《整卷难度量化与解析关键批注—通用提示词》重新处理2023—2026上海秋季高考数学材料。目标是得到“分析过后的完整试卷”，而不是只有题号和难度分的表格。

原任务明确了六项要求：

1. 每年单独产出教师阅读版Markdown，保留原题、图形、答案和解析。
2. 把教学批注放在它解释的关键步骤旁，说明入口、关键推进、边界与讲评重点。
3. 逐独立小问给出H、C、T、D、B和可追溯依据；基础题简洁，综合题展开。
4. 题干、答案、图片和重复版本有冲突时明示，不用偷偷修改后的内容冒充原卷。
5. 2023按28问，其余三年各29问，不为了表格统一硬补题。
6. 另写四年对比报告，解释难度变化、稳定压轴位置、教学重点和材料问题，并可视化重要结论。

Jev被允许用于前期筛查，但不是必需项。本次没有调用Jev，也没有用旧评分表替代重新分析。

## 2. 项目实际采用的方法

工作分为材料清点、解题审校、证据整理、程序复算、整卷比较和交付检查六个环节。

材料清点确定每份文件对应的试卷段落、题目数、已知分值、图形引用和重复版本。2025只使用汇编中的秋季卷一节，并把该节前后两处题面作为版本证据保留。

解题审校以数学对象和逻辑闭合为重点：定义域是否保留、交点是否存在、参数分类是否完整、等号是否可达、必要性是否被错当充分性。原解析可用就保留主方法；有漏洞时注明补证；无法确认题意时仅给条件性解答。

证据整理把解答分成有意义的中间结论，为每步记录输入、动作、输出、前置步骤、主要类型及六维分数。不是每移一项都增加一步，也不把同一道题的备用解法叠加计工作量。

程序复算只处理有证据的输入：逐步负荷、最高单步、最重依赖链、五项风险和最终规则分。数学是否正确、证据是否足以支持某个维度的2分，仍是审校责任，不能交给算分程序自动保证。

最后用相同口径比较年份，写明每个统计的分母。材料不全时单列覆盖率，权重不明时不伪造加权结果。

## 4. 最重要的发现

### 4.1 难点不是只集中在最后一道大题

第12、16题常出现短而需要突破的任务。例如2023的顶点身份与距离集合，2024的差集拼接与全局最大值条件，2026的特殊点配对与空间旋转轨迹。它们说明解析篇幅不能代替入口难度。

20、21题末问则更强调把突破推进到完整结论：存在性、唯一性、边界、反例和量词都不能落下。相同大题的首问往往仍是直接的基本量计算，所以必须按独立小问分析。

### 4.2 2026较高，但四年不能描述成单调变难

在本次固定规则下，2026可评分29问的均值29.17，高于2023与2024的已分析部分。推理与边界负担在中后段更明显。这个判断有具体题位支撑，尤其2026的19(2)、20(3)、21(3)。

但2023与2024的差异不宜夸大；共同可评分题位上它们接近。2025有7問冲突，均值21.91不是完整卷的可靠排序依据。换成四年共同的20个可评分题位，2025并非最低。这是覆盖率影响结论的直接例子。

### 4.3 解析看起来完整，不代表推导已经闭合

2023第16题的“总能找到”需要补存在性证明；2026第12题展示一个配置，只证明可行，还需排除其他配置。2023第21(3)证明最多三项后，仍需证明三项可以实现。

这些缺口对教师讲评比末尾分数更重要：让学生知道目前得到的是候选、必要条件、上界，还是已经充分证明的结论。

### 4.4 材料质量是分析的一部分

2025前后版本出现210/211、模≤1/模=1、偶函数条件遗漏等差异。2023、2024的圆锥曲线末问还涉及交点存在或延长方向的措辞问题。遇到这种情况，程序能算出数字并不意味着应当发布数字。

可确定的错误则明确修正。例如2025第8题等号点应为a=2、b=1/2；第17题给定数据的预测值应为204.557秒，保留两位为204.56秒。每次修正都要说明原值、修订和依据。

## 5. 从一次研究到开源项目，新增了什么

原研究脚本依赖本机文件路径和特定版式。开源首版没有直接把整个工作目录上传，而是抽出稳定的评分核心，添加明确输入格式、错误检查和回归测试。

程序会拒绝缺失的维度证据、未知风险冒充0、重复步骤ID、循环依赖、失踪的前置步骤和非法分值。重复折扣仅在明确标注机械重复组及依据时启用，不会因为两步类型相同就自动折扣。

计算使用十进制权重和非负四舍五入，避免语言默认舍入约定改变半整数结果。路径有数量限制，超出限制明确报错，不随机挑一条作为最大路径。

公开内容保留原项目的可审计价值：方法、完整提示词、115问的分析证据、争议记录、结果快照与图表。原试卷全文、第三方原图、聊天资料目录和私人绝对路径不进入仓库。

## 6. 当前不足与不能宣称的能力

第一，六维取值、步骤粒度和T仍包含判断。同一位分析者复查不能代替独立评分者的一致性检验。

第二，C只取最重连续路径，天然不能完整表示并列必做分支。B与分支数可提醒教师，但目前没有验证过的纠偏公式，因此不擅自修改D。

第三，0分只是规则对直接定义题的下限，不表示无难度。均值相差一两分也不能直接说有实质差异。

第四，解答题小问配分缺失，无法精确恢复分值加权整卷指数。2026所给文件中的总分与时间信息也不应凭习惯补上。

第五，开源程序验证输入结构和算式，不能证明自然语言证据真实、解法正确或符合某年的课程要求。自动生成证据也可能重复套话，仍需逐题检查。

第六，尚无官方原卷认证、真实答卷数据和跨地区样本。项目不能用于声称绝对难度、预测具体学生表现或自动评价教学质量。

优先解除9个冲突问，补齐可靠来源；然后请独立教师复评关键难题和异常分，记录分歧，而不是简单平均。只有材料与人工评价相对稳定后，才适合研究权重校准。

工具层面下一步是稳定数据格式和教师阅读版生成，随后是交互审核界面。OCR、AI初评、Jev筛查等能力应放在输入端，最终仍要通过证据完整性与数学审校门槛。
